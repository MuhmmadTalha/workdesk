# Office Management System

This is a comprehensive Office Management System built with Next.js and Supabase.

## Quick Start

1. Install dependencies:

   ```bash
   pnpm install
   ```

2. Set up your Supabase database:

   - Follow instructions in `SIMPLIFIED-SETUP-GUIDE.md`

3. Run the development server:

   ```bash
   pnpm dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser

## Troubleshooting

If you encounter any issues:

1. Make sure you've followed all steps in the `SIMPLIFIED-SETUP-GUIDE.md`
2. Check that your Supabase credentials are correct in `.env.local`
3. Run the Supabase Connection Test from the Admin Dashboard
4. Clear your browser cache and cookies
